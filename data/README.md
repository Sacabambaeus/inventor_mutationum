# 参照スナップショット

[English](README.en.md)

これらのファイルは、公開済みのPriMatch HTMLから抽出したビルド入力です。原資料を上書きせず、内容をそのままgzip圧縮しています。

- `references.json.gz`：32,732参照領域、既存プライマー、内蔵・旧計算結果。
- `names.json.gz`：階級・学名をキーとする22,285項目、和名の収録状況、17情報源の書誌情報。確定和名対応数6,571組と、全項目数は異なる値です。
- `manifest.tsv`：各ファイルと展開後データのSHA256、展開後サイズ、HTML内のスクリプトID。

参照配列・分類はNCBI RefSeq／GenBank・NCBI Taxonomyに基づき、和名の採用元には国立科学博物館、BISMaL、DBCLS、各分類群の目録を含みます。資料の名称・版・引用・採用件数は、生成HTMLの「出典一覧」に収録しています。

ソフトウェアのライセンスと、参照配列・名称資料の利用条件は別です。第三者資料の権利を、このリポジトリのコードの利用条件で変更するものではありません。更新時は情報源の表示と出典の根拠を保持してください。

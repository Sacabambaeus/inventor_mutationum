# Reference snapshots

[日本語](README.md)

These build inputs were extracted from the public PriMatch HTML. Original source materials were not overwritten; snapshot contents are preserved and gzip-compressed.

- `references.json.gz`: 32,732 reference regions, existing primers and built-in/legacy calls.
- `names.json.gz`: 22,285 entries keyed by rank/scientific name, Japanese-name coverage and 17 bibliographic source records. The 6,571 confirmed Japanese-name mappings are a different count from total entries.
- `manifest.tsv`: compressed and decoded SHA256, decoded sizes and HTML script IDs.

Sequences/taxonomy originate from NCBI RefSeq/GenBank and NCBI Taxonomy. Japanese-name authorities include NMNS, BISMaL, DBCLS and taxon-specific checklists. Source names, editions, citations and adoption counts are embedded in the generated HTML's Sources panel.

Software licensing and third-party sequence/name-data conditions are separate. The code's usage conditions do not change third-party rights. Preserve attribution and source evidence when updating these snapshots.
